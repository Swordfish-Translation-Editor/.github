## What Is Swordfish Translation Editor

Swordfish Translation Editor is a local Windows XLIFF helper for translation files you already keep. It gives you a named sword desk, a short xliff list, and a grid view that points back to the same job. It does not try to own every window on the PC. It sits beside the files you already use and holds only the XLIFF that is open now.
The idea behind Swordfish Translation Editor own files is small on purpose: one desk, one list, one path back. Extra grids wait for their own title. Swordfish Translation Editor starts with a local profile and does not need a complex account system.
